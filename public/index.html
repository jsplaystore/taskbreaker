Connect Google Calendar and Classroom

This talks to Google directly from your browser. Nothing is stored on our server, only locally on this device. You need your own free OAuth client ID:

  1. Go to console.cloud.google.com, create or pick a project.
  2. APIs and Services > Credentials > Create Credentials > OAuth client ID, type "Web application".
  3. Under "Authorized JavaScript origins", add .
  4. APIs and Services > Library: enable the Google Calendar API and Google Classroom API.
  5. APIs and Services > OAuth consent screen > Audience: add your own Google account under "Test users" (needed for Classroom scopes while the app is unverified).
  6. Copy the Client ID (looks like 123-abc.apps.googleusercontent.com) and paste it below.

Connect Canvas

Your access token is sent only to this app's own server for the request, not stored on disk or shared elsewhere. You can revoke it in Canvas any time.

  1. Log into Canvas, go to Account > Settings.
  2. Scroll to "Approved Integrations", click New Access Token.
  3. Give it any purpose name, generate it, copy the token (it's only shown once).
  4. Enter your Canvas domain and the token below.
